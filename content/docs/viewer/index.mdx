# Meetings Viewer

The Meetings Viewer turns raw Scrapy JSON into a browsable, filterable table.
It exists to speed up the most repetitive part of scraper development:
checking that your output is correct, field by field.

## What it does

- Loads JSON files from `data/scrapers/` in the repo.
- Renders each meeting record as a row in a data grid.
- Highlights duplicates, missing fields, and status inconsistencies.
- Lets you filter by classification, status, date range, and free-text search.

## Status values

Meeting records use four status values. These are rendered with the real
component used in the app:

## Where the data comes from

The viewer reads from `data/scrapers/<spider-name>.json`. Each file is the
output of a `scrapy crawl <spider> -O data/scrapers/<spider-name>.json` run.
The file format is a JSON array of meeting records matching the
[schema](/docs/qa/schema).

The filename without `.json` must match the spider's `name` attribute - it
becomes the slug in the viewer's URL: `fortx_council.json` is served at
`/scrapers/fortx_council`.
